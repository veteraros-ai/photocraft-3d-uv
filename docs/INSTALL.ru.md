# PhotoCraft 0.14.0 + 3D / UV

Это отдельный установочный пакет нашей доработки для **официального PhotoCraft 0.14.0 Windows x64**. Он устанавливает совместимую сборку целиком: существующий API WASM-плагинов PhotoCraft предназначен для фильтров и не позволяет добавить весь 3D-вьюпорт, интерфейс и инструменты рисования.

## Обычный запуск

После установки запускайте **PhotoCraft обычным ярлыком или из ArtCraft Launcher**. Отдельно выбирать EXE не требуется. Лаунчер хранит номер официально установленной версии; 3D/UV является локальной доработкой этой версии.

## Установка и возврат

1. Закройте PhotoCraft, предварительно сохранив работу.
2. Установите официальный PhotoCraft **0.14.0**.
3. Распакуйте весь пакет в постоянную папку, например `D:\PhotoCraft-3D-UV`.
4. Запустите `Install-3D-UV.cmd`. Если установка PhotoCraft в Program Files требует прав администратора, запустите этот файл от имени администратора.

Для возврата к официальному PhotoCraft этой же версии запустите `Restore-Official.cmd`. Сохраните папку `Backups`: в ней находится проверенная копия оригинального EXE. Установщик не закрывает приложения и не удаляет проекты.

Скрипты также принимают `-InstallDirectory "полный путь к папке PhotoCraft"`. Изменения файлов выполняются только после проверки SHA-256. Настройки перед установкой копируются в ZIP в `Backups`; оригиналы не изменяются.

Известные предыдущие сборки 3D/UV обновляются напрямую. Сохраните старый установочный пакет: установщик найдёт проверенную резервную копию официального EXE в соседних папках PhotoCraft-3D-UV, перенесёт её в новый пакет и сохранит предыдущий EXE доработки. Если старый пакет находится в другом месте, запустите `Install-Mod.ps1 -PreviousPackageDirectory "путь к старому пакету"`. Без проверенной официальной копии приложение не заменяется. Неизвестные сборки отклоняются даже при совпадении номера версии.

Интерфейс 3D/UV поддерживает русский и английский и следует настройке языка PhotoCraft. Для английского выберите Edit > Preferences > Interface > Language > English.

## Следующее обновление через лаунчер

Официальный установщик может заменить основной EXE. Пакет хранит независимую копию 3D-сборки и исходный патч, поэтому наши изменения не теряются.

- После восстановления/переустановки **той же 0.14.0** достаточно снова запустить `Install-3D-UV.cmd`.
- Для **другой версии** нужен новый пакет: доработку следует перенести на её исходники, собрать и проверить. Текущий установщик откажется заменять неизвестный или более новый EXE, чтобы не откатить программу незаметно.
- Не копируйте EXE старой 3D-сборки поверх новой версии вручную.

Этот пакет не является универсальным бинарным плагином для любых будущих версий. Он делает установку и возврат воспроизводимыми и защищает от случайного отката.

## Данные

Настройки, кисти и горячие клавиши остаются в `%APPDATA%\Photocraft`. Проекты `.pcuv` содержат модель, редактируемые текстуры, слои, подключения, настройки окружения и библиотеку изображений. `Export Textures` сохраняет отдельные плоские изображения; для сохранения проекта достаточно `.pcuv`.

## Исходники

В `source/photocraft-uv.patch` — доработка относительно тега `v0.14.0` (`ff4738810134d7f7e68b49f2e4f231b686282ff3`):

```text
git checkout v0.14.0
git apply photocraft-uv.patch
cargo build -p photocraft --features uv-workbench --release --locked
```

Сборка и временные файлы в нашей рабочей среде направлены на диск D. Лицензии PhotoCraft и дополнительных иконок находятся в `source/`.
